The merge lease is a git ref: acquire creates it, release deletes it. Once released, how long it was held is gone. Every hold-duration number in docs/adr/0001-merge-lease-hold-window.md was reconstructed by hand from run timestamps, and there is no way to answer "what does a hold cost today" without repeating that.

That matters because the calibration is stale. STALE_SECONDS is 45 minutes and MERGE_LEASE_TIMEOUT_MINUTES defaults to 60; both were derived from the pre-R1 tail, whose observed hold reached 62 minutes. R1 and R2 have since moved semantic verification, the release-authority check and the independent review out of the lock, and the retirement of blind review removes the review leg entirely. The in-lock window is now roughly gate dispatch plus run settlement. ADR 0001 R3 defers re-deriving the thresholds until measured holds exist; this card produces them.

Intent: when the control plane releases a chain lease, compute the hold from the acquiredAt already carried on the lease blob and record it where it can be read back later (activity log on the chain, at minimum). Release is control-plane only and enumerated in the ADR, so there is one place to instrument. Do not change any threshold in this card; it exists to make the next decision evidence-based rather than to act on it.

Sequencing: land after refactor/retire-blind-review-and-authority-signing merges. That branch edits packages/api/src/merge-lease.ts, merge-readiness-worker.ts and run-completion.ts, and it reshapes the hold window this card is meant to measure, so measuring the pre-refactor shape would produce data about a tail that no longer exists.

Out of scope, decided: shortening the regression run's blocking acquire so a waiting chain ends its run and is re-queued by the control plane. Rejected on 2026-08-26 as a standalone change. It trades a bounded wait for a full regression re-run including semantic verification, it has no queue fairness so a chain can starve, an unplaced run would consume the task's session budget, and it adds a not-failed-but-unfinished run terminal state to a tail that ADR 0001 finding C already showed is fragile about release timing. Revisit only if the data this card produces shows a long tail of waits.
